# Support

- Reproducible defects belong in a GitHub bug report.
- Feature and architecture proposals should start in GitHub Discussions.
- Usage and local-development questions belong in GitHub Discussions.
- Confirmed work is tracked in GitHub Issues.
- Security vulnerabilities must follow [SECURITY.md](SECURITY.md), never a
  public issue.

VinylHound is a portfolio project maintained on a best-effort basis. There is
no paid support or uptime guarantee, and the demonstration environment may be
offline when it is not actively in use.
